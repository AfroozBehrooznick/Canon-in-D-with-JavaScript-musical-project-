🎵 Canon in D — Tone.js Music Demo
A simple web based project that plays Pachelbel’s Canon in D using Tone.js.
This project demonstrates how to use JavaScript to generate musical notes directly in the browser.


✨ Features
Plays the Canon in D melody using Tone.js.
Simple and clean HTML + JS implementation.
Lightweight , no dependencies other than Tone.js.


⚙️ How to Run
Clone this repository using this code:
git clone https://github.com/AfroozBehrooznick/Canon-in-D-with-JavaScript-musical-project-

Then open the folder using this code:
cd canon-in-d

Open index.html and click the "START" button to hear the music.


🎼 How It Works
The project uses Tone.Synth() to generate sound waves.
Each note of Canon in D (D4, A3, B3, F#4, etc.) is triggered using triggerAttackRelease() with precise timing based on Tone.js’s clock.
